# Console-Based Point of Sale (POS) System

A robust core Java console application engineered strictly using Object-Oriented Programming (OOP) paradigms for retail transaction management.

## 💻 OOP Concepts Applied
- **Encapsulation:** Secured sensitive product properties and parameters.
- **Inheritance:** Extended abstract structures into dynamic item variants.
- **Polymorphic Logic:** Tailored dynamic billing rates and multi-channel payment routes.

## 🚀 Core Modules
- Stock & Inventory Management (SKU tracking).
- Real-time Transaction & Digital Bill Generator (including tax calculations).

## 🛠️ Tech Stack
- Java Standard Edition (SE)
